# Inspo Projects Saver

A free desktop browser extension for Inspo Projects.

## What it does

- Click the extension button to send the current webpage to Inspo Projects.
- Right-click a webpage and choose **Save page to Inspo Projects**.
- Right-click a product link and choose **Save link to Inspo Projects** without opening it first.
- Inspo Projects opens its normal **Save shared find** window so you can choose the board.

## Install in Chrome

1. Download and unzip the extension folder.
2. Open `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the `Inspo-Projects-Desktop-Extension` folder.
6. Pin **Inspo Projects Saver** from the Extensions menu if you want the button visible all the time.

## Install in Microsoft Edge

1. Download and unzip the extension folder.
2. Open `edge://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the `Inspo-Projects-Desktop-Extension` folder.

No paid browser-store account is required for this manual installation.
